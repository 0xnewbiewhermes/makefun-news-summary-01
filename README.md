A one-minute summary of the world's news of Wednesday 11 November 2026: the day's most consequential stories across regions and fields, each with its source named, written to /output/entry.txt by a small deterministic Node program (main.ts copies summary.txt; no network, identical bytes on every run).

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
